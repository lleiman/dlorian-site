# Art as Part of Living — Luna Selezman

Mobile-first gallery microsite for the villa exhibition in Ubud, Bali.

Run locally with `npm start`. Node.js 20+ recommended.

The site contains locally hosted, high-resolution WebP images of 16 artworks and seven villa photographs, with curatorial text adapted from the artist's 2026 presentation. No image CDN or external image hosting is required.

Railway service root: `/luna-villa-gallery`. Deployment command: `npm start`.

Live gallery: https://luna-villa-gallery-production.up.railway.app/
